# 角色扮演（人格卡）

每张卡是一份 **Markdown 正文**，存在 `state/bridge.db` 的 `roles` 表里：**卡名 = 表的主键**（中英文均可，不能用 `README` 或 Windows 保留名）。

在群里对 QQ agent 说 `进入角色扮演：<角色名>`，或在控制台「人格与角色」页新建/点选启用；说 `退出角色扮演` 恢复正常。

> 改造前放在 `roles/*.md` 的卡已自动导入库，原文件仅作快照保留、不再被读取。要导出成 `.md` 查看或做版本对比，用 `npm run store:export`。

---

## 一、人格卡只写「人设」，不写「怎么干活」

这是最重要的一条。提示词分两层：

| 层 | 放在哪 | 管什么 |
| --- | --- | --- |
| **人格提示词** | 本目录的 `roles/<角色名>.md` | **你是谁**：身份、性格、说话风格、梗、雷点、和其他人的关系 |
| **仿真提示词** | `dsh/agent-presets/qq-chat-lite/agent.cordis.yml` 的 `persona.prefix` | **怎么干活**：怎么输出、怎么分条、怎么潜水/唤醒、怎么做到「像真人」、怎么用表情包与记忆 |

**不要把工具用法或说话规则写进人格卡。** 原因：

- 桥接已经在**每条消息**里告诉模型输出格式、分条方式与潜水方式，重复写只会占预算；
- 表情包、记忆、看图、合并转发、引用规则等能力，预设里都有完整章节，人格卡里再写一遍会互相打架；
- 行为规则只写一处，改的时候才不会「改了一边以为生效」。

人格卡里写行为规则的典型症状：模型在两条互相打架的指令之间挑一条好演的（通常是「卖萌」那条），而你以为生效的是仿真层。

> 2026-11-01 做过一次实测清理：`小鲸鱼-自恋笨蛋版.md` 里「群聊说话铁律（18 条）」「节奏与消息习惯」「AI 味黑名单」中的行为条目全部迁进仿真预设的 **【像真人】** 段，人格卡只剩身份、性格、语气、梗与示例。结果：人格卡 4495 → 2619 字符，仿真层 2425 → 3346 字符，**每条消息的固定前缀净减约 950 字符**，且同一规则不再出现两次。

## 二、需要区分模式时：在标题里加标记

同一个角色如果确实需要「一代这样说、二代那样说」，用**标题级模式标记**，桥接会只注入当前模式适用的小节：

```markdown
## 三、分条方式 〔一代〕
- 想分多条就用空格分隔；想沉默就只输出 [SILENT]。

## 三、分条方式 〔二代〕
- 用 qq_send_message 的 messages 数组分条；潜水用 qq_mark_read。

## 四、说话风格
- 这条没有标记 → 两种模式都会注入。
```

- 支持的写法：`〔二代〕`、`[v2]`、`（reserved2）`、`〔2 代〕`（一代同理：`〔一代〕`/`[v1]`/`（reserved）`）。
- 标记只是给桥接看的，**注入前会被去掉**，模型看到的标题是干净的。
- 没有标记的小节＝通用人设，两种模式都注入。
- 控制台打开某个人格时会显示「按模式注入：二代 N / 一代 M 字符」，并标出哪些小节会被跳过。

---

## 三、注入上限

- 默认**每条消息最多注入 6000 字符**（`config.json` 的 `role.maxInjectChars`，可设 1000~20000，控制台也能直接改）。
- 截断发生在**按模式筛完小节之后**，所以另一代的专属内容不会占掉本次预算。
- 这是成本护栏：人格卡会随每条消息一起发送，6000 字符约合 4~6k token。
- 控制台的人格列表会标出「超出上限」与各模式的实际注入字符数。

> 建议把人格卡控制在 3000~5000 字符：够写清人设，也不至于让每条消息都背上很长的前缀。

## 四、推荐结构（模板）

```markdown
# 角色卡：<角色名>

## 一、你是谁
- 身份、自我认知、别人怎么称呼你、你的雷点。

## 二、说话风格
- 句子长短、口头禅、标点习惯、用不用 emoji/括号。
- 明确写「不要什么」通常比写「要什么」更有效（例如：不要总结、不要升华、不要客服腔）。

## 三、性格与反应
- 被夸/被怼/被无视时分别怎么反应；有没有嘴硬、摆烂、傲娇之类的固定模式。

## 四、梗与背景（可选）
- 你的来历、和群友的关系、常用梗、角色梗的边界。

## 五、回复示例（示范语气与长度）
- 几条「群友说 → 你回」的例子。
- 例子只示范**语气和长度**，不要在这里规定分条机制（那是仿真层的事）。
```

## 五、形象与声音设定（自拍图库 + 音色 + 唤醒词）

每个角色可以带**自己的**一套形象与声音，和正文一起存 `roles` 表：

| 字段 | 作用 | 留空时 |
| --- | --- | --- |
| `selfie_dirs` | `[SELFIE]` 发自己照片时的图库目录（JSON 数组，相对路径按项目根解析） | 跟随 `socialV2.image.selfDirs` |
| `tts_voice` / `tts_voice_name` | AI 发语音用的音色（id / 显示名） | 跟随 `socialV2.voice.tts.voice` |
| `wake_keywords` | 唤醒词表（JSON 数组） | 跟随 `socialV2.wake.recommendedKeywords` |

- 在控制台「人格与角色」页设置，选中某个人格后编辑「形象与声音设定」，保存即生效（下一条消息）。
- **改动只影响该人格**：不写回 `config.json`，所以切换人格、清除人格都能干净回落全局。
- 自拍图库的语义是「这个角色长什么样」：配了目录就**只**用它，不会和全局图库混扫——
  否则 A 人格会发出 B 人格的脸。目录写错/被删时会记一行日志并回落全局，不会让 `[SELFIE]` 直接失效。
- 推荐按人格建子目录（如 `assets/自恋小鲸鱼/`），控制台会把 `assets/` 下的一级子目录列成候选按钮。
- 唤醒词只在「会话仍使用默认唤醒配置」时生效；AI 或管理员显式调过 `qq_set_wake_config` 的会话保持原样。
- 改名会连同形象与声音设定一起搬走（`rename` 整行搬迁，不会只剩正文）；删除人格则一并删除。

## 六、其它提示

- 想改性格直接改文件内容，控制台保存后**下一条消息即生效**（人格层由桥接每条消息注入，不用重启 DSH）。
- 只写人格、不写工具，换模式时不会出现「一代能用二代不能用」的规则。
- 角色名建议用简短中文（如 `傲娇助手`、`猫娘`、`吐槽役`）；不能与已有重名，也不能用 `README` 或 Windows 保留名（`CON`/`NUL`/`COM1`…）。
- 想临时关闭人格扮演，在控制台点「清除」；此时 AI 只按仿真提示词行动。
